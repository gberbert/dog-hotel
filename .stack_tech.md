# 🛠️ Stack Tecnológica e Arquitetura

Este documento define a stack tecnológica, arquitetura e ferramentas utilizadas no projeto **Dog Hotel**.

## 1. 🎨 Frontend
- **Framework:** React `^19.2.0`
- **Build Tool:** Vite (`rolldown-vite@7.2.5`)
- **Linguagem:** JavaScript (ESModules) / JSX
- **Estilização:** Tailwind CSS `^3.4.17`
- **Ícones:** Lucide React `^0.554.0`
- **Gerenciamento de Estado:** React Hooks (Context API / State locale)
- **Integração Backend:** Firebase Web SDK `^12.6.0`

## 2. ⚡ Backend (Serverless)
- **Plataforma:** Firebase Cloud Functions
- **Runtime:** Node.js 20
- **SDK Functions:** `firebase-functions` `^7.0.3`
- **SDK Admin:** `firebase-admin` `^13.6.0`
- **Manipulação de Datas:** `date-fns` `^4.1.0` / `date-fns-tz` `^3.2.0`

## 3. 🗄️ Dados e Armazenamento
- **Banco de Dados:** Cloud Firestore (NoSQL)
  - Regras de segurança: `firestore.rules`
  - Índices: `firestore.indexes.json`
- **Autenticação:** Firebase Auth (Implícito via SDK)

## 4. 🛠️ DevOps e Ferramentas
- **Controle de Versão:** Git
- **Linting:** ESLint `^9.39.1`
- **Gerenciador de Pacotes:** NPM (`10.2.4` ref)
- **Sistema Operacional de Dev:** Windows 10

## 5. 🏗️ Arquitetura
O projeto segue uma arquitetura **Serverless SPA (Single Page Application)**:
- O **Frontend** (React) consome serviços diretamente do Firebase (Firestore/Auth) para operações de leitura/escrita em tempo real.
- **Business Logic** complexa ou sensível é delegada para **Cloud Functions** (Triggers de Firestore, Callable Functions ou Jobs agendados).
- **Firestore** atua como a fonte única da verdade.
